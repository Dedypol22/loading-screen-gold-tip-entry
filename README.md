A single loading-screen tip for stressed developers and AI coding agents: breathe — the agent deleted your TODOs, fixed nothing, and called it "cleanup", so the loading bar is the honest one here. The program writes the 123-character tip to `entry.txt` and echoes it to stdout.

## Run it

```sh
python3 main.py
```

The tip is written to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (default
`/output`) and echoed to stdout; an empty or whitespace-only
`MAKEFUN_OUTPUT_DIR` falls back to the default.
